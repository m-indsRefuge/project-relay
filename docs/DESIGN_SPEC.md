# Project Relay — Design Specification

**Version:** 0.2  
**Status:** Accepted / Design Frozen

This file is reserved for the accepted Project Relay design specification.

The authoritative design establishes:

- LangGraph learning and engineering as the primary project purpose;
- four small local language models;
- LangGraph as orchestration authority;
- structured shared state;
- explicit and bounded goal pursuit;
- distinct RAG, memory, and web subsystems;
- three active memory layers;
- memory consolidation and deliberate forgetting;
- a 1,000-episode controlled evaluation campaign;
- failure-aware engineering as a design invariant.

The full accepted design specification should be preserved here before M0
implementation begins.
